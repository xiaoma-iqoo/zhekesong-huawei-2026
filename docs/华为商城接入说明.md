# 华为商城接入说明（知识库外产品）

本文件说明「知衡」如何读取华为官方商城商品页，作为授权知识库之外的补充事实来源。
所有内容只在用户明确提供具体商品页链接时读取；不搜索、不登录、不猜商品编号、不绕过访问限制。

## 1. 适用范围

- 授权知识库（ima 实时 / 授权归档 / 工作区快照）覆盖的型号：仍以知识库为主，商城页可作补充来源（标为混合来源）。
- 知识库之外的华为产品（手机、平板、穿戴、新型号等）：只使用商城商品页的官方参数表作为事实来源，交付为**纯文字草稿**（没有该型号的授权图源）。
- 不适用于：商城首页、搜索页、分类页、推荐位、第三方页面；这些都不能确认具体型号。

## 2. 支持的链接格式

```
https://www.vmall.com/product/12345678901234.html
https://m.vmall.com/product/12345678901234.html
https://item.vmall.com/product/comdetail/index.html?prdId=12345678901234
https://item.vmall.com/product/comdetail/index.html?prdId=12345678901234&sbomCode=2601010519577
```

- 仅允许 HTTPS 官方域名（`www.vmall.com` / `vmall.com` / `m.vmall.com` / `item.vmall.com`）；
- 不接受账号密码、端口、锚点、相似域名；商品详情页只允许 `prdId`、`sbomCode`、`lang`、`country`、`portal`、`version` 参数，带签名/跟踪参数的链接会被拒绝；
- 旧式 `https://www.vmall.com/product/<编号>.html` 会 302 跳转到新版详情页，读取器会校验跳转目标与商品编号一致后再读取。

## 3. 读取流程（`vmall_client.py`）

1. **隔离会话**：`requests.Session()` 关闭 `trust_env`（不读取系统代理与 netrc），不携带任何应用凭据；不发送 Cookie/Authorization 请求头。
2. **重定向校验**：只接受跳转到 `item.vmall.com/product/comdetail/index.html?prdId=<同一编号>`；跳转到其他商品立即停止。
3. **访问预热**：新版商品页需要商城首页下发的 WAF Cookie，因此首次遇到跳转时先访问一次 `https://www.vmall.com/` 取得 Cookie，再读取商品页；该预热不涉及账号数据。
4. **解析主商品**：定位页面内嵌的 `"parameterData"` JSON，读取「主要参数 / 主体 / 屏幕 / 存储 / 拍摄功能 / 传输功能」等官方参数分组；`attrRemark` 中的限定说明作为「条件」保留（如圆角测量、典型值）。
5. **身份核对**：把用户填写的型号与商城主商品名称按 token 严格比对（去品牌、大小写与空格归一），只容忍末尾存储容量差异；型号、年份、系统、SE/Pro S/Ultra 等款式不一致时停止，并在提示中给出商城当前商品名称，要求用户自行改对，绝不自动替换型号。
6. **输出来源**：每条来源带 `origin: official_vmall`、官方商品页 URL（统一为 `https://www.vmall.com/product/<编号>.html`）与读取时间。

## 4. 明确不读取的内容

- 价格、促销、补贴、分期、库存、赠品、评价、问答、推荐商品、相似商品；
- 页面导航、脚本、隐藏节点、推荐/相关区块（解析只取主商品参数表）；
- 用户没有明确提供的商品链接（不会搜索或从名称猜编号）。

## 5. 知识库外产品的交付口径

- 事实来源：仅商城商品页「主要参数」表 + 主商品名称；每条事实仍要求逐字引文能在正文定位（`policy.evidence_facts`）。
- 配图：没有授权图源，因此不生成配图、不使用其他型号或网络图片；界面提示「无授权配图」，平台格式检查判为「待修改」，交付标记为**草稿**。
- 下载物：排版 HTML、素材包 ZIP（无图片）、Markdown 报告、JSON 核验记录；确认草稿后解锁下载。
- 界面文案：报告与核验结果明确标注「华为官方商城本次读取（无授权知识库配图）」「纯文字草稿」。

## 6. 安全与限额

- 单页最大 2 MB，最多 2 个商品链接；超限停止。
- 仅读取 `text/html`，不接受 JSON 或其他内容类型。
- 错误信息不回显 URL 参数、凭据或原始异常文本。
- 网络异常、需要登录、页面结构变化、WAF 拒绝时明确提示「未取得商城依据」，不降级为模型记忆。

## 7. 测试

- `tests/test_vmall_client.py` 覆盖：新旧链接格式、跟踪参数拒绝、跳转与预热、嵌入参数表解析、价格字段排除、近邻型号拒绝、内容类型/大小/状态码、网络错误脱敏、链接去重与上限；
- `tests/test_agent.py` 覆盖：知识库外产品走商城来源、无图源时按草稿交付、型号不一致在调用模型前停止；
- `tests/test_simple_flow.py` 覆盖：极简模式商城链接透传与缺链接时的提示；
- 回归命令：`python -m unittest discover -s tests`。

## 8. 已知限制

- 商城页面结构由平台维护，若 `parameterData` 结构或 WAF 行为变化，需要更新解析器并补充回归样例；
- 只支持「具体商品页」，不支持按名称搜索商品；
- 商城参数表不含授权图片，知识库外产品只能产出纯文字草稿；
- 商城参数以页面实际展示为准，型号/上市时间等字段仍需人工复核。
